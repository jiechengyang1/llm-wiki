# 麻将社区（黑马头条改版）

## 项目概述

麻将爱好者社交资讯平台，功能包括：文章发布、个人管理、用户登录、私信通知、点赞关注、热点推荐、AI问答

### 技术栈
SpringBoot、SpringCloud、MyBatis、MySQL、Redis、RabbitMQ、知识图谱

## 核心技术实现

### 用户登录
- 短信验证码 + 密码登录
- 验证码存入Redis
- MD5 + 盐值（salt）加密，优化传统MD5冲突问题
- ThreadLocal封装线程隔离全局上下文，减少用户信息数据库查询

### 缓存优化
- Redis存储：验证码、登录凭证、用户信息
- 处理缓存击穿、穿透、雪崩问题
- **先更新数据库再删除Redis**保证数据一致性
- Redis zset实现文章热度排行榜、用户活跃排行榜

### 点赞功能
- Redis Hash保存点赞信息
- 定时任务将缓存数据同步到数据库
- 实现高性能点赞

### 消息通知
- RabbitMQ实现系统通知（点赞、评论、关注通知）
- 异步解耦，提升系统效率和稳定性

### 定时任务
- XXL-JOB定时刷新文章热度、用户活跃榜单
- 缓存数据定时同步

### AI问答
- 调用麻将AI问答系统接口
- 用户可进行麻将知识提问

## 数据库设计要点

- User表：加入用户类型、雪花ID
- 邮箱激活码：防机器注册、身份核查、密码找回
- DTO/VO分层：前端请求参数用DTO，返回前端用VO
