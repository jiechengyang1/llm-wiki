# Nginx

## 基础

Nginx 是高性能 HTTP 服务器和反向代理服务器，同时支持 IMAP/POP3 代理服务。常用作负载均衡、方向代理、HTTP 缓存。

## 核心

### 正向代理与反向代理

**正向代理**：代理服务器位于**客户端**和目标服务器之间，客户端将请求发送至代理服务器，代理服务器转发给目标服务器。**服务端不知道客户端真实 IP**。常用于代理客户端访问受限制内容或保护客户端身份。

**反向代理**：代理服务器位于**服务端**接收客户端请求。**客户端不知道真实服务端地址**。常用于负载均衡、安全防护、隐藏真实服务架构。

### 核心功能

- **负载均衡**：将请求分发到多个服务器，支持轮询、权重、最少连接、IP Hash 等策略
- **反向代理**：隐藏真实服务器，提供统一入口
- **HTTP 缓存**：缓存静态资源，减少后端压力
- **SSL/TLS 终止**：处理 HTTPS 加密解密
- **动静分离**：静态资源由 Nginx 处理，动态请求转发到后端

### 负载均衡策略

- **轮询（Round Robin）**：默认策略，按顺序逐一分配
- **权重（Weight）**：按配置权重分配请求
- **最少连接（Least Connections）**：分配给连接数最少的服务器
- **IP Hash**：同一 IP 客户端始终路由到同一服务器（会话保持）
- **URL Hash**：按 URL 哈希分配，保证相同 URL 路由到同一服务器

### 高可用

Nginx 本身可作为单点风险，通常配合 Keepalived 实现高可用：
- 主备模式：主 Nginx 故障时切换到备用
- 双主模式：两个 Nginx 互相备份，共享虚拟 IP
