# 数据库基础知识

## 基本概念

| 概念 | 缩写 | 说明 |
|------|------|------|
| 数据库 | DB | 数据的集合 |
| 数据库管理系统 | DBMS | 操纵和管理数据库的软件 |
| 数据库系统 | DBS | 软件+数据库+DBA |
| 数据库管理员 | DBA | 全面管理和控制数据库 |

## 关系数据库核心术语

| 术语 | 说明 |
|------|------|
| 元组 | 表中的每一行（记录） |
| 码 | 能唯一标识实体的属性 |
| 候选码 | 能唯一标识元组的最小属性组 |
| 主码（主键） | 从候选码中选出的唯一标识 |
| 外码（外键） | 另一个关系中的主码 |
| 主属性 | 候选码中出现过的属性 |
| 非主属性 | 不包含在任何候选码中的属性 |

## ER图（Entity Relationship Diagram）

三要素：
- **实体**：矩形框表示
- **属性**：椭圆形表示
- **联系**：菱形表示（含数量对照关系）

## 数据库范式

### 1NF（第一范式）
- 属性不可再分
- 关系型数据库最基本要求

### 2NF（第二范式）
- 在1NF基础上，消除非主属性对主键的**部分函数依赖**
- 所有非主键字段必须**完全依赖**主键

### 3NF（第三范式）
- 在2NF基础上，消除非主属性对主键的**传递函数依赖**
- 所有非主键字段之间不能有依赖关系，必须相互独立

## drop vs delete vs truncate

| 操作 | 类型 | 回滚 | 作用 |
|------|------|------|------|
| DROP TABLE | DDL | 不可回滚 | 删除整张表 |
| TRUNCATE TABLE | DDL | 不可回滚 | 清空表中数据，自增ID重置 |
| DELETE FROM | DML | 可回滚 | 删除指定行数据 |

## NoSQL

**Not Only SQL**，泛指非关系型数据库，针对键值、文档、图形数据存储

### SQL vs NoSQL

| 对比 | SQL | NoSQL |
|------|-----|-------|
| 数据模型 | 关系型（表） | 键值/文档/图形 |
| 扩展方式 | 纵向（加服务器配置） | 横向（加服务器节点） |
| Schema | 固定 | 灵活 |
| 事务 | 强ACID | 最终一致性 |

### NoSQL优势
- **灵活性**：灵活架构，快速迭代
- **可扩展性**：分布式集群横向扩展
- **高性能**：针对特定数据模型优化
- **强大功能**：专用API和数据类型

代表：HBase、Cassandra、MongoDB、Redis
