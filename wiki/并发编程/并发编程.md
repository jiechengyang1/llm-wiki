# 并发编程

## 核心概念

### 进程 vs 线程

- **进程**：应用程序独立内存空间
- **线程**：进程内多条执行路径，共享进程内存

### 并行 vs 并发

- **并发**：同一实体交替执行多个任务
- **并行**：真正同时执行

### 管程(Monitor)

- 同步机制，保证互斥访问
- 每个对象都有Monitor

## 线程实现

```java
// 继承Thread
new Thread(() -> {}, "t1").start();

// 实现Runnable
new Thread(new Runnable() {}).start();

// 实现Callable + FutureTask
FutureTask ft = new FutureTask<>(() -> {});
new Thread(ft).start();
```

## 线程分类

- **用户线程**：完成业务，程序结束JVM终止
- **守护线程**：服务其他线程，如GC

## 线程状态

NEW → RUNNABLE → BLOCKED/WAITING → TERMINATED

## JUC并发包

- 原子类：AtomicInteger等，基于CAS
- 锁：ReentrantLock、ReadWriteLock
- 同步器：AQS、CountDownLatch、CyclicBarrier
- 并发集合：ConcurrentHashMap、CopyOnWriteArrayList
- 线程池：ThreadPoolExecutor、Executors
