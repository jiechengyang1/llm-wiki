# 线程基础知识

## 线程与进程

- **进程**：系统中运行的应用程序，有独立内存空间
- **线程**：轻量级进程，同进程内共享内存
- **管程(Monitor)**：同步机制，保证同一时间只有一个线程访问

## 并行 vs 并发

- **并发**：同一实体上多个事件，一台机器同时处理多个任务，同一时刻只有一个发生
- **并行**：不同实体上多个事件，多处理器同时处理多个任务

## 线程分类

- **用户线程**：完成业务操作
- **守护线程**：为其他线程服务，如GC线程，程序结束时JVM一同结束

## 线程实现

```java
new Thread(() -> {}, "t1").start();
```

## 线程生命周期

- NEW → RUNNABLE → BLOCKED/WAITING → TERMINATED
