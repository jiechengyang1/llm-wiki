# 一致性哈希

## 基础

一致性哈希算法解决分布式系统在扩容或缩容时产生过多数据迁移的问题。普通哈希算法对节点数量取模，一致性哈希对 2^32 取模，将结果组织成固定范围的哈希环。

## 核心

### 工作原理

将存储节点和数据都映射到首尾相连的哈希环上。数据存储时，沿顺时针方向找到第一个节点，该节点就是存储该数据的节点。

### 优点

在一致性哈希算法中，增加或移除一个节点，仅影响该节点在哈希环上顺时针相邻的后继节点，其他数据不受影响。

### 问题与解决方案

**数据倾斜**：一致性哈希不保证节点在哈希环上分布均匀，大数据量时可能产生大量请求集中在一个节点。

**虚拟节点**：通过引入虚拟节点解决，对每个真实节点建立多个副本映射到哈希环。假设 3 个真实节点，每个节点 3 个虚拟节点，哈希环上就有 9 个节点，大幅提高分布均匀性。

### 应用场景

- Redis Cluster 数据分片
- 分布式缓存（Memcached）
- 负载均衡器
